# Frieren Theme

An Omarchy theme inspired by the anime **Frieren: Beyond Journey's End**.

The color palette was extracted directly from the anime wallpaper, capturing the cold blue tones, emerald forest greens, and the grayish white of Frieren's design.

---

    omarchy-theme-install https://github.com/arthurr-jpg/frieren-theme-for-omarchy.git

Or via menu: `Super + Alt + Space` -> `Install` -> `Theme`

## Notes on the Waybar style

The bar itself has no background - only the functional modules (workspaces, clock, tray, battery, network, audio, active window title) render as soft pastel pills, letting the wallpaper show through the empty space. The active window title module uses light text on a darker pill for readability against the pastel palette.
